# Bartlomiej Tadel — Portfolio

Personlig portefølje bygget med React og Vite.

## Utvikling

```bash
npm install
npm run dev
```

## Bygg og publisering til GitHub Pages

```bash
npm run deploy
```

Publiserer innholdet i `dist/` til `gh-pages`-branchen. `vite.config.js` er satt opp med `base: '/portfolio/'`, som matcher GitHub Pages-URL-en for et repo med navnet `portfolio`.
